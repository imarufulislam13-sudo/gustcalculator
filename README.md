# CEF Calculator Hub

## Upload instructions

1. Rename your current working Gust Calculator file to `calculator.html`.
2. Upload these items to the root of the `gustcalculator` GitHub repository:
   - `index.html`
   - `calculator.html`
   - `gust-effect/` folder
3. Commit the files.
4. Open:
   - Hub: https://imarufulislam13-sudo.github.io/gustcalculator/
   - Gust calculator: https://imarufulislam13-sudo.github.io/gustcalculator/gust-effect/

## Important

Uploading the new `index.html` replaces the current repository homepage.  
Your existing calculator must therefore be preserved as `calculator.html`.

Future calculators can be added in folders, for example:

- concrete-volume/index.html
- rebar-weight/index.html
- unit-converter/index.html

Then update each card link in the root `index.html`.
